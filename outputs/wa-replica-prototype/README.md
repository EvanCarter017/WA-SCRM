## 推荐体验的 5 条核心闭环路径

1. **新客加微进线 → 需求建档 → 报价推进闭环**
   - 在「全周期看板（`#lifecycle`）」点击右上角 **「模拟新客加微进线」**，观察新客户自动进入 `S1 · 新进线` 并生成首响破冰待办。
   - 点击卡片 **「推进阶段」** → 选择 `S2 · 需求澄明` 录入核心需求与预计规模 → 再次推进至 `S3 · 报价推进` 填写报价金额，系统自动创建报价单并排定 24h 报价催单提醒。
2. **防漏跟进与断档自检闭环**
   - 在「全周期看板」点击防漏雷达 **「跟进断档(无计划)」**，或前往「跟进与待办（`#followups`）」切换至 **「漏跟进断档检测」**，查看处于活跃阶段却漏排下次跟进的客户（如示例客户 Harper Davis），一键补排跟进。
   - 在待办队列点击任意任务的 **「完成并衔接下一步」**，记录本次沟通结果并同步设定下次触达时间，杜绝完成一次跟进后线索悬空。
3. **报价转成交 → 发货签收 → 自动开启复购周期闭环**
   - 前往「成交与复购（`#deals`）」或打开客户的 **「360° 档案 → 报价与订单」**：
     - 对待确认报价单点击 **「转成交单」**，客户自动进入 `S4 · 成交履约`；
     - 在「订单与发货签收」对运输中订单（如 Carlos Vega 的 `ORD-202611-104`）点击 **「确认签收转复购」**，系统自动将客户流转至 `S5 · 复购培育`、计算下次预计复购日期、生成复购关怀待办，并可同步填入对应语种（英/西语）WhatsApp 消息草稿！
4. **战败/流失结构化归因 → 客户复联一键重激活回流闭环**
   - 将任意未成单客户推进至 `S7 · 流失归档`，系统要求选择结构化流失主因、自动结清过期日常待办并可设置观察复盘期。
   - 在「全周期看板」的 `S6 沉睡唤醒` / `S7 流失归档` 列（如 Rachel Green 或 Noah Wilson）点击 **「模拟客户复联」** 图标（或在聊天窗点「模拟对方回复」），立即触发红色 **「复联待重激活」** 信号；点击 **「立即重激活」** 即可保留完整历史报价与订单一键回流至活跃阶段（回流次数 +1）！
5. **点选界面备注（Alt + 左键）**
   - 在任意页面按住 **Alt + 左键** 点击任意控件，即可提交具体修改意见，自动保存在 `D:\Projects\wa-scrm\outputs\review-prompts\`。
