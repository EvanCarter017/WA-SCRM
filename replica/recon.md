## Flows

F01 选择账号 → 选择会话 → 快捷回复/文字/演示附件 → 发送前预览 → 本地消息。
F02 客户筛选 → 查看资料 → 标签/备注 → 安排跟进 → 待办完成 → 客户记录。
F03 账号列表 → 添加/编辑 → 模拟恢复在线 → 返回会话。
F04 主管视角 → 成员与账号分配/客户转交 → 切回聊手检查范围。
F05 侧栏或页签切换 → 模块判断与评审 → 导出需求 JSON。

以上是原型预期流程；未编造原站完整流程的点击数。空、无匹配、断线、错误、取消、长内容和窄屏状态纳入验证。

## Data boundary

成员、账号、客户、消息、标签组、标签、跟进和评审沿用自有原型的数据结构，不推断或复制原站数据库。源站可见空数据不代表原型不能有演示数据；两者已明确区分。

## Out of scope
