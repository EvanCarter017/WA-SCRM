# Component specification

Button：主操作、边框、文字和危险操作。默认/悬停/按下/焦点/禁用，32–40px高；本机同步保存立即反馈，不制造虚假网络加载。

Navigation：浅色侧栏的分组与子菜单，顶部可关闭页签；链接语义和键盘保留，当前页有文本、背景及aria-current共同表达。桌面可折叠，小屏打开导航对话框。

Filter panel：标签和输入明确对应，输入与选择器使用原生组件，查询/重置可用。只保留WhatsApp及既有客户条件。

Table：独立横向滚动容器、清楚表头、复选框批量选择、行内动作、总数和分页。窄屏不压缩到不可读。

Tag management：左侧分组，右侧标签列表；公共/个人范围清楚，维护权限按现有评审方案模拟。自有标签颜色不代表原站设计资产。

Conversation：上方账号选择和搜索，中间列表，右侧聊天；最右为功能工具栏。客户资料、备注、跟进通过工具栏访问。原站未连接账号的空态已观察，有消息状态为按需求补足的演示。

Form/dialog：原生dialog管理焦点，表单包含取消、字段错误、首个错误聚焦；长表单内容滚动，底部动作可达。Escape关闭。

Feedback：保存、连接模拟、标签撤销和草稿状态明确；演示消息不会被描述为真实投递成功。减少动态效果设置生效。
