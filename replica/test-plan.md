# 原型测试计划

目标仅为本地复刻原型，不向原站发送测试请求。通过宿主授权的 CUA 浏览器工具点击界面，以角色、标签和稳定页面标识定位。当前不安装独立浏览器、不运行真实账号或后端测试。

| 编号 | 流程 | 验证 |
| --- | --- | --- |
| F01-H1 | 账号与会话 | 账号筛选、客户选择、快捷回复预览、本地消息 |
| F01-E1 | 断线 | 保存草稿、取消重连、模拟恢复、空白发送禁用 |
| F01-E2 | 切换/刷新 | 客户文字与演示附件分别保存，不跨客户携带 |
| F02-H1 | 客户资料 | 资料/记录/备注页签、备注保存、标签撤销 |
| F02-H2 | 跟进 | 表单错误、取消、创建、完成与重新打开 |
| F02-E1 | 客户查询 | 阶段/标签/文字、无匹配、批量标签与清除筛选 |
| F03-H1 | 账号管理 | 表格查询、添加、编辑、空账号和连接提示 |
| F04-H1 | 团队 | 成员扩展、账号分配、客户转交、聊手数据范围 |
| F05-H1 | 导航 | 侧栏分组、收起/展开、多页签关闭与重开、前进后退 |
| F05-H2 | 标签维护 | 左分组右列表、公共/个人、添加编辑、查询 |
| F05-H3 | 评审 | 范围判断、评审保存、JSON导出及原清单保护 |
| A11Y-E1 | 键盘 | 搜索快捷键、错误聚焦、Escape、可见焦点 |
| RESP-E1 | 布局 | 1440、当前客户端984、390及320宽度，表格独立横向滚动 |

不适用：支付、生产登录、OAuth授权、真实翻译、限流和消息投递，全部在本轮范围外。文件语法、需求等价、历史文件哈希、无外部业务请求及颜色对比单独检查。
